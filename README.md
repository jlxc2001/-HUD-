# HUD接收端

HUD接收端用于接收同一局域网内发送端传来的导航卡片截图，并以横屏 HUD 方式显示。

## 主要功能

- 监听 `45678` 端口接收导航卡片图片
- 横屏、全屏、屏幕常亮显示
- 未接收画面前 6 秒无触摸后自动隐藏；接收画面后 3 秒无触摸后自动隐藏状态信息和设置按钮
- 设置界面支持：
  - HUD反射倒像模式
  - 适应模式 / 铺满模式
  - GPS 车速表开关
  - 时间显示开关
- 单击屏幕显示状态栏，双击屏幕打开设置

## 使用建议

发送端和接收端需要连接到同一个 WiFi/热点。建议在路由器或热点管理中为接收端设置静态 IP，避免每次连接后 IP 变化。不要使用开启了 AP 隔离的 WiFi，否则发送端可能无法访问接收端。

## 主页/Launcher 模式

设置中提供“主页开关”。开启后会跳转到系统默认主页应用设置，用户可以手动选择“HUD接收端”作为默认 Launcher。Android 不允许应用静默设置默认主页，因此必须由用户确认。
