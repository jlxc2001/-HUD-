# HUD接收端

用于接收 HUD发射端通过 WiFi 局域网发送来的导航卡片图像，并在接收端设备上以全屏 HUD 方式显示。

## 主要功能

- 接收导航卡片图片并全屏显示。
- 支持 HUD反射倒像模式。
- 支持适应模式 / 铺满模式。
- 支持 GPS 车速表和时间显示。
- 支持作为 Launcher/Home 使用。
- 未收到投屏前：状态文字 6 秒无触摸自动隐藏，可作为车速/时间 HUD 使用。
- 收到投屏后：状态文字 3 秒无触摸自动隐藏。
- 收到发射端停止指令后：自动清空导航画面，黑屏，仅保留车速表和时间信息。

## 使用建议

1. 建议接收端和车机端连接同一个 WiFi 或手机热点。
2. 建议给接收端设置静态 IP，方便车机端固定填写。
3. 若设备本身没有系统级镜像，可在设置里开启“HUD反射倒像模式”。
